# OpenCodeGo 用量助手（油猴脚本）v0.9.6

在 `https://opencode.ai` 仪表盘上**全量抓取并保存用量历史**，提供**用量分析**（当天/1d/7d/30d/全部/自定义，输入输出/缓存命中率/费用）与**使用历史**。

- RPC 与页面一致：`POST /_server`，参数走 seroval JSON body（`X-Server-Id` / `X-Server-Instance` 头）。
- 内容指纹去重：`请求时间 + 输入/输出/推理/缓存读(+缓存写/模型/费用)` 相同 => 同一条记录。
- 持久历史（IndexedDB，**无过期**，仅手动清空）；历史完整时全量拉取**命中历史即停止翻页**，历史不完整时翻到底并标记完整。
- 全量拉取可停止、互斥、防重复页；日志持久化；面板可拖拽调整大小并记忆；**中/英文界面**（默认跟随浏览器语言）。

## 使用（数据 / 使用历史 / 日志）

- **数据页（含分析）**：
  - 刷新工作区 / **拉取全量用量**（可停止、互斥；历史完整时命中历史提前停止）/ 清空历史；
  - 时间范围（当天/1d/7d/30d/全部/自定义）→ **开始分析**（用持久历史）或 **拉取最新并分析**（先全量刷新）；
  - 指标卡片（请求/输入/输出/推理/缓存读/缓存写/费用/缓存命中率）、按模型（含每模型缓存命中率）、按天明细、导出分析报告。
- **使用历史页**：表格化展示**近期 API 使用情况和成本**——列顺序：请求时间、模型、**输入、推理、缓存读、输出、成本($)**（无会话列）；
  时间格式 24 小时制 `yyyy/MM/dd HH:mm:ss`；支持时间范围（当天/1d/7d/30d/全部/自定义）、最多显示前 300 条、**导出 CSV**（同列序，Excel 可直接打开，带 BOM）。
- **日志页**：复制/导出/清空；最近 300 条持久化；成功日志只记摘要；**日志列表高度随面板大小自适应**。
- 面板：可拖动**四边/四角**调整大小（切换标签页不重置，**大小记住到下次会话**）；头部有**语言切换**（Auto/中文/English，默认跟随浏览器语言，选择会记住）；“清空历史”按钮清空持久数据。

## 历史与翻页（v0.4.3 起）

- **指纹去重**：`timeCreated | inputTokens | outputTokens | reasoningTokens | cacheReadTokens | cacheWrite5mTokens | cacheWrite1hTokens | model | cost` 相同 => 同一条。
- **持久化**：无 TTL、无过期，只有“清空历史”才删除；`complete` 标记是否完整全量（页面捕获不会提升）。
- **命中历史即停止**：仅当历史已完整时启用——再次拉取时当前页出现与历史指纹重合的记录即停止翻页，本次新数据与历史数据按指纹合并；**历史不完整时不会提前停止**，会一直翻到底并标记完整（避免误报“历史不完整”）。
- **停止按钮**：任务进行中数据页显示 ⏹ 停止，点击立即中断并保留已拉部分。
- **翻页**：`usage.list(ws, page)` 每页 50 条，直到返回 < 50 条或命中历史；整页与上一页完全相同判定分页失效停止。

## 已知限制

- 只读查询（全量用量）；写操作未包含。
- 函数 ID 为 2026-08-10 快照（当前仅 `workspaces` / `usage.list`）；官方更新失效时需重新抓取 bundle 提取并同步 `FN_IDS`。
- 全量拉取上限 500 页（2.5 万条），可配 `maxUsagePages`；需真实登录。
