# OpenCodeGo 用量助手（油猴脚本）v0.8.1

在 `https://opencode.ai` 仪表盘上**全量抓取并保存用量历史**，提供**用量分析**（当天/1d/7d/30d/自定义，输入输出/缓存命中率/费用）。
- RPC 与页面一致：`POST /_server`，参数走 seroval JSON body（`X-Server-Id` / `X-Server-Instance` 头）。
- 内容指纹去重：`请求时间 + 输入/输出/推理/缓存读(+缓存写/模型/费用)` 相同 => 同一条记录。
- 持久历史（IndexedDB，**无过期**，仅手动清空）；滚动刷新**命中历史即停止翻页**，直接拿历史数据相加。
- 全量拉取可停止、互斥、防重复页；日志与开关。

> v0.8.0 变更：界面文案“缓存”全部改为“历史”（“缓存命中率/缓存读/缓存写”等模型指标名保留）；**移除头部“总开关/日志”勾选框**；**面板可拖动边缘调整大小**（切换标签页不重置尺寸）；**分析默认“当天”**，切换时间范围自动分析；**使用历史自定义“从/到”时间随范围联动**（选近 7 天时自动填入当前时间到 7 天前）。
> v0.7.0 变更：移除 Keys；**“数据”与“分析”合并**；新增 **「使用历史」tab**；移除独立新标签页方案与“调试”开关。
> v0.5.0 已移除：自检协议、一键全部、用量(第1页)、Go套餐、账单、支付记录、查看捕获。

## 安装

Tampermonkey/Violentmonkey → 新建脚本 → 粘贴 `opencodego-dashboard.user.js` 保存（或拖入安装）→ 登录 `https://opencode.ai`。

## 使用（数据 / 使用历史 / 日志）

- **数据页（含分析）**：
  - 刷新工作区 / **拉取全量用量**（可停止、互斥、命中历史提前停止）/ 清空历史；
  - 时间范围（当天/1d/7d/30d/自定义）→ **开始分析**（用持久历史）或 **拉取最新并分析**（先全量刷新）；
  - 指标卡片（请求/输入/输出/推理/缓存读/缓存写/费用/缓存命中率）、按模型、按天明细、导出分析报告。
- **使用历史页**：表格化展示**近期 API 使用情况和成本**——列顺序：请求时间、模型、**输入、推理、缓存读、输出、成本($)**（无会话列）；
  时间格式 24 小时制 `yyyy/MM/dd HH:mm:ss`；支持时间范围（当天/1d/7d/30d/全部/自定义）、最多显示前 300 条、**导出 CSV**（同列序，Excel 可直接打开，带 BOM）。
- **日志页**：复制/导出/清空；最近 300 条持久化；成功日志只记摘要。
- 面板：可拖动**四边/四角**调整大小（切换标签页不重置）；“清空历史”按钮清空持久数据。

## 历史与翻页（v0.4.3 起）

- **指纹去重**：`timeCreated | inputTokens | outputTokens | reasoningTokens | cacheReadTokens | cacheWrite5mTokens | cacheWrite1hTokens | model | cost` 相同 => 同一条。
- **持久化**：无 TTL、无过期，只有“清空历史”才删除；`complete` 标记是否完整全量（页面捕获不会提升）。
- **命中历史即停止**：再次拉取时当前页出现与历史指纹重合的记录 => 立即停止翻页，不再请求后续页，本次新数据与历史数据按指纹合并；历史不完整时会提示“可能缺更早记录”。
- **停止按钮**：任务进行中数据页显示 ⏹ 停止，点击立即中断并保留已拉部分。
- **翻页**：`usage.list(ws, page)` 每页 50 条，直到返回 < 50 条或命中历史；整页与上一页完全相同判定分页失效停止。

## 已知限制

- 只读查询（全量用量）；写操作未包含。
- 函数 ID 为 2026-08-10 快照（当前仅 `workspaces` / `usage.list`）；官方更新失效时需重新抓取 bundle 提取并同步 `FN_IDS`。
- 全量拉取上限 500 页（2.5 万条），可配 `maxUsagePages`；需真实登录。
